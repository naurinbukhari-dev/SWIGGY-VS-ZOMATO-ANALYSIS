# Swiggy vs Zomato Analysis

## Project Overview
This project presents a comparative analysis of Swiggy and Zomato using Power BI.

## Objectives
- Compare Swiggy and Zomato performance.
- Analyze sales and order trends.
- Understand customer preferences.
- Compare business performance across different cities.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis
